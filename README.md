# College Discovery Platform

A web application to compare colleges based on:

- Fees
- Placement percentage
- Courses
- Ratings
- Location

## Features

- College comparison
- Detailed college pages
- Q&A discussion section
- Modern UI using Next.js and Tailwind CSS

## Tech Stack

Frontend:

- Next.js
- Tailwind CSS

Backend:

- Node.js
- Express.js

Database:

- JSON Server
